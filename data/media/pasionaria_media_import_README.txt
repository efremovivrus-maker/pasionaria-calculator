PASIONARIA — медиакаталог для конструктора коммерческих предложений

Источник: пользовательская YML-выгрузка от 03.11.2026 18:53.

Файлы:
- pasionaria_media_catalog_2026-11-03.json: записи товаров с offer_id, model, article, full_article, color, color_number, size, cover, images.
- pasionaria_media_model_color_index_2026-11-03.json: индекс по точным названию модели и цвету с offer_ids и первой иллюстрацией.

Порядок изображений сохранен; cover = первый <picture> каждой товарной позиции.

Рекомендованное применение:
1. Добавить JSON как статический источник данных или импортировать в каталог проекта. Не помещать весь массив в клиентский bundle без необходимости.
2. При наличии идентификатора товара выбирать строго по offer_id; иначе по полному артикулу; иначе по артикулу + цвету; иначе показывать менеджеру варианты по модели и цвету для ручного выбора.
3. Сохранять в позиции КП идентификатор выбранного offer, URL конкретной фотографии и цвет (при наличии). Размеры индивидуально рассчитываемого изделия не следует сопоставлять с готовым SKU как обязательный фильтр.
4. Для PDF изображение скачивать/конвертировать на сервере или через доверенный image proxy с контролем доменов, таймаутом и fallback. Поддержать PDF без фото.
5. Не использовать цены из YML в калькуляторе; цвета относятся к готовым товарам и не заменяют будущий справочник доступных цветов ткани.
6. Добавить периодическую контролируемую пересборку каталога из свежего YML, если источник обновляется.

ВАЖНО: фотографии хранятся как URL, сами JPG в репозиторий не скачаны. Приложение забирает их через прокси только с pro.pasionaria.ru по HTTP или HTTPS. Цены из YML не используются.
